# ⭐ About the Project

**AI Resume Builder** is a full-stack web application that helps users create professional resumes using AI.

Users can automatically generate:

- Professional resume summaries
- Project descriptions
- Job experience bullet points
- Skills suggestions

The application includes:

- Live resume preview
- CRUD functionality
- AI powered resume generation
- PDF export functionality

This project demonstrates a **complete MERN stack application integrated with AI.**

# 🔧 Installation

Clone the repository

```bash
git clone https://github.com/PushpakGanganmale/ai_resume_builder.git
cd ai_resume_builder
```

Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

---

# 🔑 Environment Variables

Create `.env` file inside the **server** folder.

```
MONGO_URI=your_mongodb_connection_string
PORT=4000
GROQ_API_KEY=your_api_key
```

---

# ▶ Run Locally

Start backend server

```bash
cd server
npm run dev
```

Start frontend

```bash
cd client
npm start
```

Open the application

```
http://localhost:5173
```
